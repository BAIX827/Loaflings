# Loaflings / 摸鱼灵

Passive desktop companion game.

## Core Concept

The way the player uses their computer shapes a unique creature.

computer behaviour
→ interpretation
→ creature traits
→ Loafling
→ collection
→ ecosystem

## Core Signals

- typing
- clicks
- mouse movement
- focus time
- idle time
- window switching

## Product Principles

- 95% passive, 5% interaction
- Idle time should also create value
- Behaviour should shape creatures, not only generate currency
- Each completed Loafling becomes part of the player's permanent collection
- Privacy-first: track behavioural statistics, never typed content
