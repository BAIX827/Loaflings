# Loaflings Version 2：自主奇遇与每日记忆

状态：V2.1–V2.3 已有本地实现；可控数据重放与 Electron 窗口检查已完成，真实桌面的长时频率与动画体验仍待验收。更新时间：2026-09-24。

相关构想及暂缓项目见 [功能候选清单](FEATURE_IDEAS.md)。本方案延续 [PROJECT.md](../PROJECT.md) 的被动桌宠定位。

## 目标

玩家照常使用电脑时，摸鱼灵偶尔根据已有的匿名行为统计做出安静反应。玩家可以回看这些小事；成年收藏时，能读到一段与真实行为和奇遇对应的记忆。没有看到桌面演出，也不会丢失记录。

目标体验：**“我今天做过的事，变成了这只摸鱼灵经历的一天。”**

## 实施前起点（历史背景）

- SENSE 已记录点击、按键、鼠标距离、空闲/活跃时长、专注时段、窗口切换和活跃小时分布；没有输入内容或窗口标题。
- CORE 已输出工作/探索/梦境能量、性格、品质、特质及结算时的一条空闲事件。现有结算事件不是实时奇遇日志，不能当作已经发生过的桌面演出。
- 桌面已有表情、云朵、呼吸/短暂空闲表现及本地收藏，但没有持久的当天奇遇列表。
- 未完成的蛋可以跨日继续或重开；V2 记忆需要明确按“本地日历日”和“当前蛋”各自归属，不能因跨日或重复保存虚构事件。

## 优先范围与交付顺序

### V2.1 奇遇记录：先让事情真实发生、可靠保存

先选以下四种情境，全部来自已有统计；阈值在实现时按实际传感器表现校准：

| 情境 | 可用依据 | 记忆方向 |
| --- | --- | --- |
| 专注结束 | 已完成专注时段的时长 | 建造者安静地完成一件小作品 |
| 空闲归来 | 空闲时长增长后再次活跃 | 梦想家睡醒、做梦或带回一段梦的碎片 |
| 探索一阵 | 鼠标距离在观察区间内明显增长 | 探索者沿桌角旅行 |
| 窗口穿梭 | 窗口切换计数在观察区间内明显增长 | 摸鱼灵在几扇小门间探头 |

1. 依据数值变化生成事件，不用每天固定配额凑故事。现有专注时段只记录已完成的时长，因此“正在专注”不能被冒充为已完成的专注事件。
2. 每条奇遇保存事件 ID、本地日期、发生时间、类型、触发依据摘要和用于展示的性格版本。记录存本地，不保存按键内容、窗口标题或逐次输入轨迹。
3. 同一情境有冷却与每日上限；重启、重复轮询、跨日同步和重复收藏不能重复生成同一事件。无权限或数据不足时不臆造“专注了多久”之类的事实。
4. “今天”面板可查看简短时间线；没有奇遇时给平和的空状态。未完成的蛋跨日继续时，旧日奇遇保持原日期并归属同一颗蛋；选择新蛋时，旧奇遇保留在本地历史中，但不进入新蛋的孵化记忆。

验收：用可控的行为统计重放触发/未触发情境；验证重复读取、重启、跨日继续/新蛋和无感应数据；本地记录不含文本内容。此阶段可以先用文字和现有角色状态，不依赖新美术。

### V2.2 桌面小演出：让性格变得看得见

1. 奇遇发生时，用现有表情、云朵和轻微柔软动作给出短暂反应；桌面保持可穿透和低干扰。建造者、探索者、梦想家至少各有一种辨识度不同的表现或文案。
2. 演出不弹系统通知，不遮挡工作，不要求点击。关闭窗口、错过演出或暂时处于蛋阶段时，已记录的奇遇仍可在时间线查看。
3. 首批只复用现有可用素材；如需新增姿态或道具，先按 [角色规范](../character/LOAFLING_CHARACTER_SPEC_UPDATED.md) 和资产生产规则审稿，再纳入这一阶段。

验收：在真实桌面运行中检查演出频率、交互穿透、不同性格、窄窗口和长时间运行；降低动画偏好的环境应能安全退回静态表现。

### V2.3 孵化记忆：解释这只摸鱼灵的一天

1. 成年结算时，用真实的能量、性格、特质和已发生奇遇生成简短中文/英文说明，解释主要影响。句子只表达数据足以支持的事实；不评价生产力好坏。
2. 收藏条目保存这份记忆快照与事件引用。跨日继续的蛋可以引用其成长期间多个日期的奇遇；新蛋只引用自己的奇遇。以后修改文案、设置或继续使用电脑，不会让旧收藏的故事凭空变化。
3. 在当前结果和历史收藏中都能回看；旧版本收藏缺少记忆时显示兼容的简洁摘要，不编造历史奇遇。

验收：同一份行为资料得到稳定且可解释的结果；中英文信息一致；重复保存、重启及历史数据迁移后，收藏内容保持稳定。

## 本轮暂缓

纪念品、分享图、延迟探索、生态箱、跨周变异、季节事件和新增大量动作不作为 V2.1–V2.3 的完成条件。它们保留在 [功能候选清单](FEATURE_IDEAS.md)。现有金币系统不能成为奇遇触发或性格生成的必要条件。

## 产品验收线

- 玩家正常工作或休息，无需主动操作就可能遇到奇遇；即使错过桌面演出，也能从“今天”回看。
- 事件类型和文案能够追溯到已有匿名统计；缺乏数据时诚实显示缺乏数据。
- 休息与空闲有积极或中性的故事价值，不制造照料压力。
- 桌面演出保持短、轻、低频，不抢焦点、不拦截桌面操作。
- 已完成摸鱼灵的记忆能永久留在本地收藏；跨日选择与旧数据兼容。
- 全流程不读取或保存输入内容、窗口标题、文档或截图；不默认上传或分享。

## 当前实现与待验收

- 奇遇类型为专注结束、空闲归来、鼠标探索和窗口穿梭。当前阈值分别为已结束的 25 分钟专注、观察到至少 60 秒空闲后再次活跃、观察区间累计 0.5 米鼠标移动、累计 3 次窗口切换；每类每天最多两次，并有 30 分钟冷却。
- 事件与数值依据存于本机 `userData/adventures.json`。每颗蛋有独立 ID；重复读取、重启、跨日继续与换新蛋的归属由本地检查点处理。今天面板和背包中的“奇遇”可查看记录。
- 成体使用现有表情、云朵和短暂轻动作回应新事件。收藏保存按真实结算及该蛋事件生成的中英文记忆快照和事件引用；旧收藏显示不编造奇遇的兼容摘要。
- 首次启用或重启后的当前统计只作为观察基线，不从旧记录倒推奇遇。每天的限额按事件类型和本地日期计算；换新蛋不会抹掉旧蛋的历史。记忆文案最多叙述两条已记录奇遇，同时保留该蛋全部事件 ID 引用。
- 首次启动引导提供中英文游玩路径；设置可重新打开。玩家可从“今日”看当天奇遇，从“背包 → 奇遇”看历史，从成年结果或历史收藏看孵化记忆。金币、图鉴和换装仍按各自原有规则运行。
- 已用可控资料重放、持久化测试和 Electron 窄窗口检查验证主要路径。真实桌面长时间运行时的触发频率、不同性格演出与动画偏好仍需实际体验验收。

## 阈值与展示选择

当前阈值和文案见上节。后续根据真实桌面体验校准频率与展示位置时，仍以上述验收线为准；不要为了凑满每天的事件数生成没有行为依据的奇遇。
