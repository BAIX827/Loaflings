# Loaflings 功能候选清单

状态：产品构想与优先级建议，尚非全部已批准的开发需求。更新时间：2026-09-23。

## 判断标准

以 [PROJECT.md](../PROJECT.md) 为准：电脑使用习惯塑造摸鱼灵；95% 被动、5% 互动；空闲也有价值；完成的摸鱼灵进入永久收藏；只记录行为统计，不读取输入内容。`reference/` 中的概念属于灵感，不自动成为需求。

当前已经具备六阶段成长、可调整的孵化目标、三种可达性格与三档品质、模块化成年外观、换装、日历/收藏/图鉴、累计统计和本地金币钱包。CORE 已在结算结果中生成特质和单条空闲事件，桌面也有呼吸与表情/云朵变化；尚没有贯穿白天并可回看的奇遇记录。候选功能围绕这一缺口排序。

| 候选 | 玩家会感受到什么 | 现有基础 / 主要依赖 | 建议 |
| --- | --- | --- | --- |
| 自主奇遇与今日记忆 | 工作或离开时，摸鱼灵偶尔做一件小事；错过也能回看 | SENSE 数值、CORE 能量/事件、桌面表现；需要独立的事件记录与跨日规则 | **V2 首选** |
| 性格专属日常表现 | 建造者、探索者、梦想家会以不同方式回应同一段日子 | 已有性格、模块化表情和云朵；新增动作素材需按角色规范审核 | **V2 首选，先复用现有素材** |
| 孵化解释与日记 | 收藏时知道这只摸鱼灵由哪些行为和奇遇形成 | 结算结果、行为统计、收藏；需要中文/英文文案及事实映射 | **V2 首选** |
| 小纪念品 | 奇遇可能留下一个可收藏的小物，成为那一天的证据 | 先有稳定的奇遇记录；再设计物品类型、去重与展示 | V2 后续候选 |
| 每日记忆卡 / 分享卡 | 将摸鱼灵与当天故事保存或主动分享 | 先有日记；分享图需要本地导出与隐私选项 | V2 后续候选 |
| 一次点击的延迟探索 | 玩家选一个方向，摸鱼灵稍后自己回来 | 奇遇与纪念品系统、延迟完成/重启恢复规则 | 后续版本 |
| 旧摸鱼灵生态箱 | 已收藏的摸鱼灵一起生活、互动 | 稳定的性格动作、收藏展示和多角色性能 | 中期目标 |
| 跨多日行为变异 | 长期习惯慢慢孕育新类型 | 可靠的多日统计、额外视觉部件与概率平衡 | 中期目标 |
| 昼夜/季节氛围 | 桌面角落随时间柔和变化 | 本地时间、氛围素材；不得成为数值优势 | 可穿插的美术扩充 |
| 温和的发现提示 | 玩家知道还有什么可能被发现 | 图鉴与真实可达的规则；避免透露不存在的内容 | 图鉴扩充时评估 |

## 体验边界

- 奇遇应安静、短暂、可错过；不要求玩家立刻点击，也不通过系统通知打断工作。
- 空闲、低活跃或休息不应被写成惩罚或失败。不要加入饥饿、死亡、连续签到损失等照料压力。
- 表现可以用性格、现有表情/云朵/轻微姿态开始。新增角色动作与视觉变体应遵循 [角色规范](../character/LOAFLING_CHARACTER_SPEC_UPDATED.md)，保留柔软身体、简洁面孔与悬浮云。
- 现有金币功能保持次要收藏进度；打字/点击不直接兑换核心性格、变异或稀有度。现行规则见 [金币系统第一版](COIN_ECONOMY.md)。
- 不以 AI 聊天、待办事项或大型小游戏作为这条主循环的前置条件。
- 分享内容必须由玩家主动导出。具体活动数值、日期等可识别个人作息的信息，默认不放入对外卡片。

## 取舍理由

优先级最高的三项能复用已有信号、性格、结算、桌面和收藏，并让“行为 → 解释 → 生物 → 记忆”在实际游玩中可感知。纪念品、分享卡和生态箱在这条链稳定后更容易设计，也能避免先增加一个只有空壳的收集系统。具体 Version 2 范围、实施顺序和验收见 [Version 2 方案](VERSION_2_PLAN.md)。
